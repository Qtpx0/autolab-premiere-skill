# 06 — Interactive Personal Workflow Skill Builder Guide
# คู่มือให้ AI พาผู้ใช้สร้าง "สกิลเวิร์กโฟลว์ประจำตัว" (Personal Production Workflow Skill) แบบจับมือทำทีละขั้น

เอกสารนี้คือ **คู่มือปฏิบัติการสำหรับ AI Agent** เมื่อผู้ใช้งานติดตั้งชุดสกิลมาตรฐาน `autolab-premiere` เสร็จแล้ว และต้องการสร้าง **"สกิลเวิร์กโฟลว์ส่วนตัว" (Personal Workflow Skill)** เพื่อให้ AI จำโครงสร้างโฟลเดอร์บนเครื่อง, โครงสร้าง Bin ใน Premiere Pro, ชุดพรีเซ็ตหลัก (`Master Profile`), กรอบ `.mogrt`, ป้ายโปรโมท, สูตรตั้งค่า Speed Assist, และขั้นตอนการส่งออกไฟล์ของผู้ใช้คนนั้นโดยเฉพาะ

---

## 🎯 1. ทำไมต้องแยก "สกิลมาตรฐานกลาง" กับ "สกิลเวิร์กโฟลว์ประจำตัว"?

| มิติเปรียบเทียบ | 1. สกิลมาตรฐานกลาง (`autolab-premiere`) | 2. สกิลเวิร์กโฟลว์ประจำตัว (`<my-premiere-workflow>`) |
| :--- | :--- | :--- |
| **หน้าที่หลัก** | คู่มือการใช้เครื่องมือ MCP ทั้ง 38 (41 รวม Aliases) + 434 คำสั่ง (`Engine Manual`) | สูตรการทำงานและโฟลเดอร์เฉพาะเครื่องของผู้ใช้ (`Personal Autopilot SOP`) |
| **สิ่งที่เก็บไว้ข้างใน** | ชื่อคำสั่ง, พารามิเตอร์, วิธีเรียก `af_pipeline`, `🎯 จัดกรอบ`, `✂️ ย่อชื่อ` | พาธโฟลเดอร์จริงบน Disk, ชื่อ Bin ใน Premiere, ชื่อพรีเซ็ต/กรอบประจำช่อง, กฎตั้งค่า Speed |
| **การอัปเดตเวอร์ชัน** | ดึงอัปเดต (`git pull`) จากรีโปกลางได้ตลอดโดยไม่ทับข้อมูลส่วนตัว | เก็บแยกในโฟลเดอร์สกิลของเครื่องตนเอง (ปลอดภัย ไม่รั่วไหลสู่สาธารณะ) |

> [!IMPORTANT]
> **กฎเหล็กสำหรับ AI Agent:**
> - **ห้ามนำพาธโฟลเดอร์ส่วนตัว ชื่อเพจ หรือชื่อโปรเจกต์ของผู้ใช้ ไปเขียนทับลงในไฟล์ของสกิลกลาง `autolab-premiere` เด็ดขาด!**
> - ให้สร้างเป็นสกิลแยกต่างหากที่โฟลเดอร์สกิลของผู้ใช้ เช่น:
>   - `.agents/skills/<ชื่อสกิลของผู้ใช้>/SKILL.md` (สำหรับโปรเจกต์/Workspace)
>   - หรือ `~/.gemini/skills/<ชื่อสกิลของผู้ใช้>/SKILL.md` / `~/.claude/skills/<ชื่อสกิลของผู้ใช้>/SKILL.md` (สำหรับ Global Skill ประจำเครื่อง)

## 🤖 2. ขั้นตอนที่ AI ต้องทำทันทีเมื่อผู้ใช้สั่ง *"ช่วยสร้างสกิลประจำตัว"* (AI Guided Onboarding Flow)

เมื่อผู้ใช้พูดว่า **"ช่วยสร้างสกิลประจำตัว"**, **"ตั้งค่าเวิร์กโฟลว์ของฉัน"**, หรือเพิ่งเริ่มใช้งานครั้งแรกและยังไม่รู้จะเริ่มต้นอย่างไร **ห้ามให้ผู้ใช้เขียนไฟล์เองเด็ดขาด!** ให้ AI เป็นฝ่ายพาทำตาม **4 เฟส (Auto-Discovery ➔ Interview ➔ Preview ➔ Generate)** ดังนี้:

```mermaid
flowchart LR
    A["Phase 1: AI สำรวจเครื่องอัตโนมัติ<br>(ดึงรายชื่อพรีเซ็ต/กรอบ/Bin จริง)"] --> B["Phase 2: AI สัมภาษณ์ผู้ใช้ 6 ข้อ<br>(มีตัวเลือกพร้อมคำแนะนำ)"]
    B --> C["Phase 3: สรุปพิมพ์เขียวให้ตรวจ<br>(ยืนยันความถูกต้อง)"]
    C --> D["Phase 4: สร้างไฟล์ SKILL.md ประจำตัว<br>+ ทดสอบรันจริง 1 งาน"]
```

### 🔍 Phase 1: AI สำรวจและจัดกลุ่มข้อมูลจริงในเครื่องผู้ใช้ก่อนถาม (Zero-Guessing Auto-Discovery & Smart Clustering)

**ผู้ใช้ทั่วไปและพนักงานตัดต่อไม่ใช่ Dev — ห้ามให้ผู้ใช้พิมพ์ชื่อไฟล์หรือคิดโครงสร้างระบบเองเด็ดขาด!**
ก่อนเริ่มถามคำถาม ให้ AI รันคำสั่งสำรวจข้อมูลที่มีอยู่ในโปรแกรม AutoLab และ Premiere Pro ของผู้ใช้ แล้ว **จัดกลุ่ม (Cluster)** ขึ้นมาแสดงให้ผู้ใช้เห็นภาพทันที:

1. **ดึงรายชื่อชุดพรีเซ็ตหลัก (`masterProfiles`), กรอบ (`frames`), ป้ายโปรโมท (`promos`), และค่าสเกล (`transforms`) ที่ผู้ใช้มีอยู่ในเครื่อง:**
   ```json
   // เรียก Tool: autolab_list_templates
   {}
   ```
2. **ดึงรายชื่อ Root Bin ใน Premiere Pro (เพื่อดูว่าผู้ใช้จัดหมวดหมู่ไว้อย่างไร เช่น หมวดหนัง, หมวดรายการ, หรือแยกตามชื่อเรื่อง):**
   ```json
   // เรียก Tool: autolab_pr_bin_tree
   {
     "maxDepth": 2,
     "includeClips": false
   }
   ```
3. **เช็คสถานะหน้าจอปัจจุบันใน AutoLab (ถ้าเปิด Premiere Pro อยู่):**
   ```json
   // เรียก Tool: autolab_get_status
   {}
   ```
4. **AI วิเคราะห์และจัดกลุ่มป้ายโปรโมท (`promos`) + กรอบ (`frames`) อัตโนมัติก่อนแสดงให้ผู้ใช้ดู:**
   - **ตรวจจับการแยกหมวดงาน (Content Category Prefix):** เช่น มีไฟล์ที่แยกหมวดหมู่เนื้อหา (หมวดรายการ vs หมวดหนัง/ซีรีส์) หรือไม่?
   - **ตรวจจับการแยกคนตัด / เพจ / เครื่องที่ใช้ร่วมกัน (Shared-PC Owner / Page Suffix):** เช่น มีรหัสต่อท้ายชื่อป้ายโปรโมทอย่าง `_Team1` คู่กับ `_Team2`, หรือ `_A` คู่กับ `_B`, หรือชื่อพนักงานหลายคนในคอมเครื่องเดียวกันหรือไม่?
   - **ตรวจจับแบรนด์สปอนเซอร์ (Sponsor Brand):** เช่น `BrandA`, `BrandB`, ฯลฯ
5. **แสดงผลสิ่งที่ตรวจพบแบบจัดกลุ่มเข้าใจง่ายให้ผู้ใช้ดู:**
   > *"ผมสแกนเทมเพลตและโปรเจกต์ในเครื่องนี้เรียบร้อยแล้ว พบข้อมูลโครงสร้างดังนี้ครับ:*
   > - *หมวดโฟลเดอร์หลักใน Premiere Pro (Root Bins): `[เช่น หมวดหนัง, หมวดรายการ, หรือรายชื่อเรื่อง]`*
   > - *ชุดพรีเซ็ตหลัก (Master Profiles): `[รายชื่อที่ตรวจพบ]`*
   > - *กรอบ `.mogrt` (Frames): `[แยกกลุ่มกรอบตามหมวดหมู่]`*
   > - *ป้ายโปรโมท `.mogrt` (Promos):*
   >   - *กลุ่มงานหนัง/ซีรีส์: `[เช่น Movie_Promo_A, Movie_Promo_B]`*
   >   - *กลุ่มงานรายการ: `[เช่น Show_Promo_A, Show_Promo_B]`*
   > *เดี๋ยวผมช่วยวางระบบแยกโฟลเดอร์และเลือกป้ายโปรโมทอัตโนมัติให้เลย คุณแค่ตอบยืนยันสั้นๆ ตามตัวเลือกด้านล่างนี้ครับ"*

### 💬 Phase 2: AI สัมภาษณ์พร้อมเสนอระบบสำเร็จรูปให้ผู้ใช้เลือกง่ายๆ (6 หมวดมาตรฐาน + ระบบคอมใช้ร่วมกันหลายคน/หลายโปรโม)

ให้ AI ถามผู้ใช้ด้วยภาษาคนทั่วไป พร้อม **เสนอทางเลือกสำเร็จรูป (Recommended Blueprint)** ให้ผู้ใช้แค่ตอบตกลงหรือระบุคำค้นสั้นๆ:

#### 📌 คำถามหมวดที่ 1: โฟลเดอร์เก็บคลิปบน Disk, คลังไฟล์ตัวเต็ม (`rawDiskRoot`), และการเช็คสต็อก
- **สิ่งที่ AI ต้องถามผู้ใช้:**
  1. *"เวลาตัดและ Export คลิปเสร็จแล้ว คุณเก็บไฟล์ `.mp4` ไว้ที่โฟลเดอร์หลักไหนในเครื่องครับ (`diskRoot`)? (เช่น `D:\Clips\Output` หรือ `E:\Work\Videos`)"*
  2. *"คุณมีโฟลเดอร์คลังเก็บไฟล์หนัง/รายการตัวเต็มที่ดาวน์โหลดมาพักไว้ในเครื่องก่อนนำเข้า Premiere Pro (`rawDiskRoot`) ไหมครับ? (เช่น `F:\RawMedia` หรือแยกหมวด `\หนัง`, `\รายการ`) — หากระบุไว้ เวลาฟุตดิบใน Premiere Pro หมด AI จะสามารถเช็คเฉพาะโฟลเดอร์เรื่องนั้นว่ามีตอนถัดไปเหลือในเครื่องไหม และสั่ง Import ตอนถัดไปเข้า Premiere Pro มาตัดต่อให้เองอัตโนมัติโดยไม่ต้องลากไฟล์มือครับ"*
  3. *"มีการแยกโฟลเดอร์ย่อยตามประเภทงานหรือตามเพจ/คนตัดไหมครับ? เช่น แยกโฟลเดอร์ `รายการ`, `หนัง`, แยกโฟลเดอร์ย่อยตามคนตัด/เพจ (เช่น `\เพจA`, `\เพจB`), หรือแยกตามตอน `ep1`, `ep2`, `ep3` สำหรับซีรีส์?"*
  4. *"มีโฟลเดอร์ไหนที่ต้องข้ามไม่ให้นับเป็นสต็อกไหมครับ (เช่น โฟลเดอร์ `ลงแล้ว` หรือ `จบแล้ว`)? และมีการตั้งชื่อโฟลเดอร์แจ้งเตือนเวลาคลิปใกล้หมด (เช่น ต่อท้ายว่า `- - จะหมด`) ที่ต้องการให้ AI เปลี่ยนชื่อออกให้อัตโนมัติตอนตัดเติมไหมครับ?"*

#### 📌 คำถามหมวดที่ 2: การจัดระเบียบ Bin ใน Premiere Pro & ระบบคลังฟุตดิบกลาง (Premiere Bin Hygiene & Central Raw Pool Routing)
- **สิ่งที่ AI ต้องถามผู้ใช้:**
  1. *"ใน Premiere Pro ตรวจพบ Root Bin ดังนี้: `[...]` สำหรับสกิลนี้ โฟลเดอร์งานของคุณจะอยู่ใน Root Bin ไหนเป็นหลักครับ? (เช่น `"หนัง"` หรือ `"รายการ"`) — เพื่อที่เวลา AI สั่งตรวจสต็อกหรือค้นหา ระบบจะได้ส่ง `categoryBin` ไปล็อกสแกนเฉพาะหมวดนี้ ตัดคลิปหมวดอื่นทิ้ง 100% ไม่ปนกัน และคืนผลลัพธ์เร็วใน 0.05 วินาที"*
  2. *"ใน Premiere Pro คุณวางไฟล์ฟุตเทจดิบที่เตรียมตัดไว้ในคลังกลาง Sub-bin ชื่อว่าอะไรครับ? (เช่น `<ชื่อเรื่อง>/รอ` หรือ `รอตัด`)"*
  3. *"กรณีตัดแยกหลายเพจ หรือมีหลายคนใช้คอมร่วมกัน คุณใช้ระบบ **Central Raw Pool ➔ Work Bin** (พักฟุตดิบรวมไว้ที่ `<ชื่อเรื่อง>/รอ` แล้วเวลาสั่งตัดของเพจไหน ให้ AI ใช้ `pr_move_item` ดึงคลิป 1 ตอนออกมาใส่ Work Bin แยกของเพจนั้น เช่น `<ชื่อเรื่อง> - <ชื่อเพจ/คนตัด>`) เลยไหมครับ?"*
  4. *"ก่อนเริ่มตัดตอนใหม่ใน Work Bin ต้องการให้ AI ลบโฟลเดอร์ `HIGHLIGHTS_` เก่าเฉพาะที่อยู่ใต้ Work Bin ของเพจนั้นทิ้งให้อัตโนมัติ (โดยห้ามแตะต้อง `HIGHLIGHTS_` ของคลังกลางหรือของเพจอื่นเด็ดขาด) เลยไหมครับ?"*
  5. *"สำหรับงานซีรีส์ที่แบ่งเป็นตอนๆ (`EP`) ต้องการให้ AI สร้าง Bin ย่อย `ep1`, `ep2`... ใน Premiere Pro คู่กับโฟลเดอร์ `ep1`, `ep2`... บน Disk เพื่อไม่ให้คลิปแต่ละตอนปนกันด้วยไหมครับ?"*

#### 📌 คำถามหมวดที่ 3: สูตรตั้งค่า Auto Highlights & Speed Assist แยกตามประเภทงาน
- **สิ่งที่ AI ต้องถามผู้ใช้:**
  1. *"ในการตัด Auto Highlights คุณต้องการใช้ค่ามาตรฐานแนะนำของระบบเลยไหมครับ? ได้แก่:*
     - *Engine: `⚡ Cloud AI Direct Audio` (`gemini_audio`)*
     - *จำนวนช็อตเป้าหมาย: `100 Shots`*
     - *ความยาวต่อช็อต: `60-90 วินาที` (`0.5-1.5 นาที`)*
     - *ความละเอียด Sequence: `1920x1080` (`1080p FHD`)"*
  2. *"เรื่องการเร่งความเร็วคลิป (`SPEED ASSIST`):*
     - *งานประเภทไหนที่ **ไม่ต้องใส่ Speed** (`enableSpeed: false` — เช่น รายการทีวี/วาไรตี้)?*
     - *งานประเภทไหนที่ **ต้องเปิด Speed Assist** (`enableSpeed: true` — เช่น หนัง/ละคร/ซีรีส์)? และใช้ค่า Speed เท่าไหร่ครับ (เช่น ค่ามาตรฐานยอดนิยม: `Speed 1.15×`, `tone -2`, `cents 3`, เปิด `maintainPitch`)?"*

  3. *"กรณีคุณสั่งตัดหลายเรื่องพร้อมกันที่มีทั้งงานหมวดเปิด Speed (เช่น หนัง 1.15×) และหมวดปิด Speed (เช่น รายการทีวี) เพื่อป้องกันไม่ให้สปีดเสียงตีกัน คุณต้องการให้ AI **แบ่งกลุ่มรัน Auto Highlights แยกตามสูตรสปีดอัตโนมัติ (Autonomous Speed Partitioning)** โดยรันกลุ่มแรกให้เสร็จแล้วสลับสูตรไปรันกลุ่มสองต่อเนื่องจนจบโดยไม่ต้องหยุดถามเลยใช่ไหมครับ?"*

#### 📌 คำถามหมวดที่ 4: การวางระบบเลือกป้ายโปรโมท & กรอบอัตโนมัติ (กรณีคอมใช้ร่วมกันหลายคน / ตัดหลายเพจ / มีหลายโปรโม)
> [!IMPORTANT]
> **เมื่อ AI เห็นว่าในเครื่องมีป้ายโปรโมทหลายตัว (เช่น แยกรหัสคน `_A` / `_B` หรือแยกหมวดหมู่เนื้อหา) ห้ามถามคำถามกว้างๆ ให้ User งง!** ให้ AI **เสนอระบบแยกอัตโนมัติจากชื่อโฟลเดอร์ (2D Folder-Tag Routing System)** ให้ User เลือกยืนยันทันที:

- **สิ่งที่ AI ต้องเสนอและถามผู้ใช้:**
  1. **วิธีแยกคนตัด / เพจ บนคอมเครื่องเดียวกัน (Shared-Machine Owner/Page Tagging):**
     - *"ในเครื่องนี้มีป้ายโปรโมทแยกเป็นรหัส (เช่น `_A` กับ `_B`) ผมขอวางระบบแยกอัตโนมัติจากชื่อโฟลเดอร์ให้แบบนี้เลยไหมครับ:*
       - *ถ้าชื่อโฟลเดอร์/Bin **เป็นชื่อเรื่องปกติ** (ไม่มีคำต่อท้าย) ➔ ให้ถือเป็นงานของ **คนหลัก (เช่น รหัส `_A`)** อัตโนมัติ*

## 🚨 1. กฎการจัดการโฟลเดอร์บน Disk และ Bin ใน Premiere Pro

### 1.1 ค่าคอนฟิกหลักประจำเครื่อง
- **คลังไฟล์ตัวเต็มในเครื่อง (`rawDiskRoot` — ก่อนเอาเข้า Premiere Pro):** `<ใส่พาธคลังไฟล์ตัวเต็มของผู้ใช้ (ถ้ามี) — ห้ามสแกนตอนเช็คสต็อกเด็ดขาด!>`
- **โฟลเดอร์หลักสำหรับเก็บคลิปที่ตัดเสร็จแล้ว (`diskRoot`):** `<ใส่พาธโฟลเดอร์หลักของผู้ใช้ เช่น D:\Clips\Output>`
- **Root Bin หลักใน Premiere Pro (`categoryBin`):** `<ชื่อ Root Bin เช่น หมวดหนัง หรือ หมวดรายการ>`
- **โฟลเดอร์ที่ต้องข้ามไม่สแกนเมื่อเช็คสต็อก (`excludeDirs`):** `<เช่น ลงแล้ว,จบแล้ว>`
- **Sub-bin คลังพักฟุตดิบกลาง (`sourceSubBin`):** `<เช่น รอ หรือ รอตัด>`
- **ป้ายแจ้งเตือนสต็อกใกล้หมดที่ต้องเปลี่ยนชื่อออกก่อนตัด:** `<เช่น - - จะหมด>`

### 1.2 สถาปัตยกรรมคลังฟุตดิบกลางและการดึงไฟล์ 3 ชั้น (Central Raw Pool ➔ Work Bin & 3-Tier Pull Protocol)
- **คลังฟุตดิบกลาง (`Raw Pool`):** ฟุตเทจดิบของเรื่องจะถูกพักรวมไว้ที่ `<ชื่อเรื่อง>/<waitingSubBin>` เสมอ **ห้ามตัดตรงในคลังกลางเด็ดขาด!**
- **Work Bin ประจำเพจ/คนตัด/ตอน:**
  - กรณีตัดลงเพจหลัก (`<เช่น Team1>`): Work Bin คือ `<ชื่อเรื่อง>`
  - กรณีตัดลงเพจย่อย (`<เช่น Team2>`): Work Bin คือ `<ชื่อเรื่อง> - <คำต่อท้ายเพจที่ 2>` (หากยังไม่มี ให้ใช้ `pr_create_bin` สร้างทันที)
  - กรณีตัดซีรีส์แบ่งตอน (`epX`): Work Bin คือ `<หมวด>/<ชื่อเรื่อง>/ep<เลขตอน>`
- **กลไกการดึงไฟล์ 3 ชั้น เวลาสั่งตัด (3-Tier Pull Protocol):**
  1. **ชั้นที่ 1 (Work Bin):** ตรวจสอบใน Work Bin เป้าหมายก่อนว่ามีฟุตเทจค้างอยู่หรือไม่ ถ้ามีให้ใช้ไฟล์นั้น
  2. **ชั้นที่ 2 (Bin พักไฟล์ `<waitingSubBin>` ใน Premiere Pro):** ถ้า Work Bin ว่างเปล่า ➔ ใช้ `pr_move_item` ดึงฟุตเทจ 1 คลิปจากคลังกลาง `<ชื่อเรื่อง>/<waitingSubBin>` มาไว้ที่ Work Bin เป้าหมาย
  3. **ชั้นที่ 3 (คลังไฟล์ตัวเต็มในเครื่อง `rawDiskRoot` — 1-Call JSX Smart Fuzzy Import):** ถ้า `pr_inspect` รอบแรกไม่พบใน Premiere Pro หรือในคลังกลาง `<ชื่อเรื่อง>/<waitingSubBin>` ว่างเปล่า (`waiting: 0`) และผู้ใช้กำหนด `rawDiskRoot` ไว้ ➔ **ห้ามยิง `pr_bin_tree` ซ้ำใน Premiere และห้ามรัน PowerShell ค้นไฟล์ใน `rawDiskRoot` เด็ดขาด!** ให้ยิง `autolab_call_jsx` (`{"script": "..."}`) เพียง 1 คำสั่งเดียวเพื่อค้นหาโฟลเดอร์เรื่องใน `<rawDiskRoot>` แบบแยกคำค้น (Multi-Token Fuzzy Match รองรับภาษาไทย UTF-8 100%) + สร้าง Work Bin เป้าหมาย + สั่ง `app.project.importFiles()` นำเข้าฟุตเทจทันที แล้วลุยตัดต่อต่อเนื่องทันที! แต่ถ้า `autolab_call_jsx` ไม่พบตอนถัดไปใน `rawDiskRoot` ➔ **STOP ทันที** และรายงานผู้ใช้ 1 บรรทัด ห้ามเดาหรือสลับไปดึงไฟล์เรื่องอื่นเด็ดขาด!
- **กฎการลบ `HIGHLIGHTS_` (Strict Isolation):** ลบ `HIGHLIGHTS_` เก่า **เฉพาะที่อยู่ใต้ Work Bin ของตัวเองเท่านั้น** ห้ามแตะต้องหรือลบ `HIGHLIGHTS_` ของคลังกลางหรือของเพจอื่นเด็ดขาด!

### 1.3 แยกตามประเภทงาน
1. **งานรายการ (TV Shows / Variety):**
   - **Disk Path:** `<พาธโฟลเดอร์รายการ>\<เพจหรือคนตัด>`
   - **Premiere Bin:** ลบ `HIGHLIGHTS_` เก่าใน Work Bin ของเพจนั้น ➔ ดึงฟุตเทจ 1 ตอนจากคลังกลาง `<ชื่อเรื่อง>/รอ` เข้ามาที่ Work Bin ของเพจนั้น
2. **งานหนังเดี่ยว (Single Movies):**
   - **Disk Path:** `<พาธโฟลเดอร์หนังเดี่ยว>`
   - **Premiere Bin:** ลบ `HIGHLIGHTS_` เก่าที่ส่งออกแล้ว ➔ ย้ายฟุตเทจจาก `<Sub-bin พักไฟล์>` ออกมาที่ Bin เรื่องนั้น
3. **งานซีรีส์/ละครแบ่งตอน (`ep1`, `ep2`, `ep3`...):**
   - ดูเลขตอนจากชื่อไฟล์ใน `<Sub-bin พักไฟล์>`
   - สร้าง Sub-bin `ep<เลขตอน>` ใน Premiere Pro และสร้างโฟลเดอร์ย่อย `ep<เลขตอน>` บน Disk คู่กันเสมอ (ใช้คำสั่งเดียว `autolab_pr_prepare_ep`)

### 1.4 กฎเช็คสต็อก 1 คำสั่งจบ (`< 1s`) และตารางสรุปผลมาตรฐาน (Standard Stock Dashboard Table Protocol)
- **ยิง `autolab_pr_inspect` เพียง 1 ครั้งเดียวจบ:** ส่ง `{ "diskRoot": "<diskRoot>", "categoryBin": "<categoryBin>", "excludeDirs": "<excludeDirs>", "lowStockThreshold": 25, "scanPremiere": true }` โดยไม่ต้องใส่ `queries`
- **⛔ ข้อห้ามเด็ดขาดตอนเช็คสต็อก:** ห้ามเรียก `autolab_pr_bin_tree` กวาดทั้งหมวดงาน (เพราะจะล้นลง `output.txt`), ห้ามรัน PowerShell (`Get-ChildItem`) นับไฟล์บน Disk ซ้ำซ้อน (เพราะ `diskFolders` นับรวมซับโฟลเดอร์มาครบ 100% แล้ว), และห้ามยิง `pr_inspect` รอบที่ 2
- **📊 มาตรฐานการแสดงผลตาราง Dashboard และการตีความสถานะ (บังคับ 100%):**
  - ห้ามรายงานผลเช็คสต็อกเป็น Bulleted List หรือย่อหน้าซ้อนกันเด็ดขาด
  - ต้องตีตาราง Markdown Table เสมอ: `| ลำดับ | เรื่อง | สต็อกบน Disk | ตอนที่เหลือบน Disk | สถานะใน Premiere Pro | Action ที่ต้องทำ |`
  - **การตีความ `queryAudit` ตอนเช็คสต็อก:** เฉพาะเรื่องที่ `waiting > 0` (`readyToCut`) เท่านั้นที่แปลว่า **มีฟุตเทจดิบใหม่พร้อมตัดทันที (🟢)** ส่วนเรื่องที่ `waiting: 0` (แม้จะขึ้น `ALL_CUT` หรือ `NEEDS_RECOVERY` ที่มี `recoverable > 0`) แปลว่า **ฟุตเทจถูกตัดผ่าน Auto Highlights และย้ายเก็บเข้า `ไฟล์ต้นฉบับ` ไปหมดแล้ว (ไม่มีฟุตดิบใหม่รอตัด)** ต้องรายงานว่า *"ตัดครบแล้ว — ต้องโหลดฟุตเทจใหม่มาเติม"* ห้ามสรุปหลอกว่าพร้อมตัดใหม่เด็ดขาด (กู้ไฟล์จาก `ไฟล์ต้นฉบับ` เมื่อผู้ใช้สั่งให้กู้มาตัดซ้ำเท่านั้น)
  - เรียงจากเรื่องที่สต็อกเหลือน้อยสุด/หมดขึ้นก่อน (🔴 0–2 คลิป ➔ 🟡 ปานกลาง ➔ 🟢 มีฟุตเทจพร้อมตัดทันที ➔ ⚪ สต็อกปลอดภัย) พร้อมสรุป Action ใต้ตาราง 2 บรรทัด

## 🎯 3. ตารางจับคู่ป้ายโปรโมท 2 มิติ (Multi-User / Multi-Promo Routing Matrix) & การจัดกรอบอัตโนมัติ

> **กฎเหล็กสำหรับ AI Agent:** ห้ามส่งชื่อป้ายโปรโมทแบบย่อ (เช่น `"BrandA"`) เข้า MCP เด็ดขาด! ต้องดูชื่อโฟลเดอร์/Bin แล้วแปลงเป็น **ชื่อไฟล์ `.mogrt` เต็มเป๊ะ** ตามตารางด้านล่างนี้เสมอ:

### 3.1 ตารางแยกป้ายโปรโมทตาม `[ประเภทงาน]` × `[รหัสคนตัด / เพจบนชื่อโฟลเดอร์]`
| เงื่อนไขชื่อโฟลเดอร์ / Bin ใน Premiere Pro | ประเภทงาน | ผู้ใช้ / เพจ | ชื่อป้ายโปรโมทเต็มที่ต้องส่งเข้า MCP (`promo`) | กรอบเริ่มต้น (`frame`) |
| :--- | :--- | :--- | :--- | :--- |
| หมวดหนัง/ซีรีส์ และ **ไม่มี** คำต่อท้ายคนที่ 2 | หนัง / ซีรีส์ | คนหลัก (`<เช่น Team1>`) | `"<เช่น Movie_Promo_Team1>"` | `"<เช่น Frame_Movie_01>"` (หรือตามสั่ง) |
| หมวดหนัง/ซีรีส์ และ **มี** คำต่อท้ายคนที่ 2 | หนัง / ซีรีส์ | คนที่ 2 (`<เช่น Team2>`) | `"<เช่น Movie_Promo_Team2>"` | `"<เช่น Frame_Movie_01>"` (หรือตามสั่ง) |
| งานรายการทีวี และ **ไม่มี** คำต่อท้ายคนที่ 2 | รายการ | คนหลัก (`<เช่น Team1>`) | `"<เช่น Show_Promo_Team1>"` | ตาม Master Profile รายการ |
| งานรายการทีวี และ **มี** คำต่อท้ายคนที่ 2 | รายการ | คนที่ 2 (`<เช่น Team2>`) | `"<เช่น Show_Promo_Team2>"` | ตาม Master Profile รายการ |

### 3.2 การเลือกใช้ Master Profile vs ระบบวัดกรอบอัตโนมัติ (`af_tuner_auto_fit` / `⚡ Auto Scale`)
- **งานรายการทีวี (TV Shows):** ใช้ Master Profile ได้เลย (เช่น `profileName: "<ชื่อ Master Profile รายการ>"`) พร้อมส่ง `autoFit: true` เสมอ — หากตัดลงเพจคนที่ 2 ให้ส่ง `promo` ทับตามตารางข้อ 3.1
- **งานหนัง / ซีรีส์ (Movies & Series): แนะนำใช้ Auto-Scale (`autoFit: true`) เป็น default เสมอ** เพราะหนังแต่ละเรื่องมีขอบดำฝังในเนื้อวิดีโอ (Hardcoded Letterbox) ไม่เท่ากัน แม้ความละเอียดจะเป็น `1920x1080` เหมือนกันก็ตาม — Auto-Scale จะวัดจริงทุกครั้งจึงแม่นกว่า Master Profile ที่อาจล้าหลังหรือไม่ตรงกับเรื่องใหม่
- **กรณีเรื่องใหม่ทุกประเภทที่ยังไม่มี Master Profile (หรือผู้ใช้ระบุแค่ชื่อกรอบ เช่น `"<ชื่อกรอบ>"`):**
  - ไม่ต้องเดาค่า `scale` เองเด็ดขาด! ให้เรียก `autolab_af_tuner_auto_fit` (หรือส่ง `autoFit: true` ใน `autolab_af_pipeline`) เพื่อให้ระบบวัดช่องใส `.mogrt` + สแกนตัดขอบดำวิดีโอ 3 ช่วงเวลา (`120s`, `360s`, `720s`) คำนวณสเกลพอดีกรอบระดับพิกเซลให้อัตโนมัติทันที
- **ค่ามาตรฐาน Topbar & ป้ายโปรโมท:**
  - ขนาด `1080x1920`, `promoStart: 5` (เริ่มวิที่ 5), `promoInterval: 0` (ลากจนจบคลิป), `injectHeadline: true`, `autoCutState: 0` (ปิด AutoCut เสมอ)
