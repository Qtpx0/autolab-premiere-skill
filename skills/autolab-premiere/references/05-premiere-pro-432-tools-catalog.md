# 05 — Complete Adobe Premiere Pro MCP Tool Catalog (432 Tools · v1.24.1)
# สารบัญและคู่มืออ้างอิงเครื่องมือ Adobe Premiere Pro MCP ครบทั้ง 432 คำสั่ง

เอกสารนี้รวบรวมรายชื่อเครื่องมือทั้งหมด **432 คำสั่ง** จากเซิร์ฟเวอร์ `premiere-pro` MCP (`AutoLab/mcp/premiere-pro-mcp/runtime/index.js`, เวอร์ชัน `1.24.1`) แยกตาม 8 หมวดหมู่การทำงาน พร้อมพารามิเตอร์หลักที่ใช้งานจริง (**`ตัวหนา`** = บังคับใส่ `required`, `ตัวปกติ` = `optional`) และคำอธิบายภาษาไทยครบทุกคำสั่ง

> **💡 กฎสำคัญในการเลือกใช้เครื่องมือ:**
> - สำหรับงาน **Auto Highlights**, **Auto Frame Queue**, **🎯 จัดกรอบ (Vision Framing)**, **✨ ตั้งชื่อ AI (`variety`)**, และ **✂️ ย่อชื่อที่ยาว (`Name Refiner`)** ให้ใช้เครื่องมือตระกูล `autolab_*` ในไฟล์ [`02-autolab-30-tools-reference.md`](02-autolab-30-tools-reference.md) เป็นหลักเสมอ
> - ใช้เครื่องมือในไฟล์นี้เมื่อต้องการสำรวจโปรเจกต์, จัดการ Bin/Sequence, แคปภาพหน้าจอ (`export_frame`), ปรับแต่งคลิป/เสียง/สี/เอฟเฟกต์เชิงลึก หรือสั่งเรนเดอร์ส่งออกไฟล์
